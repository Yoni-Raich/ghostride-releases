# GhostRide

אפליקציית אנדרואיד אישית: מקליטים רכיבה ודופק, מתחרים ברכיבה קודמת (״הרוח״) וצופים במגמות לאורך זמן.

ה-APK העדכני נמצא ב-[Releases](../../releases/latest). החבילה: `com.yoni.ghostride`.

- מרוץ מול השיא האישי, הרכיבה האחרונה או הראשונה, על מפה וקטורית תלת-ממדית.
- דופק חי משעון Amazfit (BLE) וסנכרון מ-Zepp דרך Health Connect.
- מגמות: 7 ימים מול 7 קודמים, זמן מסלול, מהירות ודופק לאורך זמן.
